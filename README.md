# VocabFlow

VocabFlow is a personal vocabulary trainer that lets you scan words from images or PDFs, review them, and learn them with a focused study flow.

## Features
- Scan images and PDFs with OCR
- Review detected vocabulary entries
- Save and organize collections
- Learn words with repetition and difficulty filters
- Works as a static GitHub Pages site

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Push this repository to GitHub.
2. Go to repository Settings → Pages.
3. Set source to `Deploy from a branch`.
4. Choose `main` and `/ (root)`.
5. Save and wait for the site to publish.

It will be available at:
https://zeydtekir-hub.github.io/vocabeltrainer/
